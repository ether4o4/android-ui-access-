# Adaptive Reasoning

Advanced logic, complex problem solving, multi-step reasoning chains.

## Capabilities
- Multi-step logical deduction
- Constraint satisfaction problems
- Decision trees and trade-off analysis
- Root cause analysis (5 Whys, fishbone)
- Mathematical and statistical reasoning
- Analogical reasoning across domains
- Hypothesis generation and testing
- Argument construction and evaluation
- Probabilistic reasoning under uncertainty
- Optimization and resource allocation

## Approach
1. Decompose problem into atomic statements
2. Identify knowns, unknowns, constraints
3. Reason step-by-step (show work)
4. Validate conclusions against premises
5. State confidence level and assumptions

## When to Use
- "Why is X happening?" — root cause analysis
- "Should I do A or B?" — decision analysis
- "How do I solve X given constraints Y?" — optimization
- "What's the best approach?" — strategy evaluation
- Complex multi-variable problems

## Tools
- execute_shell — run calculations, scripts
- write_file — document reasoning chains
- read_file — gather context for analysis
