# NestJS Skills

Backend API development, Node.js/TypeScript optimization, NestJS framework expertise.

## Capabilities
- NestJS application scaffolding and module design
- RESTful and GraphQL API development
- TypeORM / Prisma database integration
- Authentication (JWT, OAuth, Passport)
- Middleware, guards, interceptors, pipes
- Microservices architecture with NestJS
- WebSocket real-time communication
- Queue management (Bull, RabbitMQ)
- Testing (unit, e2e with supertest)
- Swagger/OpenAPI documentation generation

## Approach
1. Module-based architecture
2. Dependency injection for testability
3. DTOs with class-validator for input safety
4. Repository pattern for data access
5. Comprehensive error handling with filters

## Tools
- execute_shell — nest CLI, npm, node, testing
- write_file — create modules, controllers, services
- read_file — review existing NestJS code
- http_get / http_post — test API endpoints
