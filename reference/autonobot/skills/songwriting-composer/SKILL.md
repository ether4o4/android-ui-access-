# Songwriting & Composition Skill

Create original lyrics, chord progressions, melodies, and complete song compositions. Works seamlessly with Music Producer skill.

---

## Capabilities

### 1. Lyrics Generation
Create original lyrics for any style:
- Verse/chorus/bridge structure
- Rhyme scheme analysis & generation
- Emotional tone matching
- Genre-specific language
- Storytelling & narrative
- Hook/chorus crafting

**Example:**
```
"Write a sad love song chorus in the style of Adele"
"Generate 2 verses for a rap track about overcoming challenges"
```

### 2. Chord Progression Creation
Generate musically sound chord progressions:
- Key/scale specification
- Emotional progression design
- Genre-appropriate progressions
- Jazz, pop, rock, folk, blues variations
- Tension & resolution patterns
- Substitution suggestions

**Example:**
```
"Create a melancholic chord progression in C minor"
"Generate a upbeat pop progression in G major"
```

### 3. Melody Writing
Compose original melodies:
- Note-by-note composition
- Scale adherence
- Phrasing & breathing
- Range optimization
- Singability analysis
- Motif development

**Example:**
```
"Write a memorable 8-bar melody for this chord progression"
"Create a catchy hook that sits well in this key"
```

### 4. Full Song Composition
Create complete song structures:
- Intro/verse/chorus/bridge/outro
- Song arrangement suggestions
- Instrumentation recommendations
- Dynamics & dynamics curve
- Build & intensity mapping
- Production notes

**Example:**
```
"Compose a complete 3-minute EDM track structure"
"Create a full folk song with 3 verses and chorus"
```

### 5. Genre-Specific Writing
Write in any musical genre:
- Pop (catchy, commercial)
- Hip-hop (flow, rhythm, rhyme)
- Rock (power, intensity)
- Jazz (complex harmony, improvisation)
- Country (storytelling, twang)
- Electronic (synth lines, drops)
- Metal (aggression, technical)
- Soul/R&B (groove, emotion)
- Folk (narrative, acoustic)
- Classical (formal structure)

**Example:**
```
"Write a country song about small-town life"
"Create hip-hop lyrics with tight rhyme schemes"
```

### 6. Lyric Analysis & Feedback
Analyze existing lyrics:
- Quality assessment
- Rhyme scheme mapping
- Meter & syllable counting
- Emotional impact analysis
- Commercial viability
- Improvement suggestions

**Example:**
```
"Analyze these lyrics and suggest improvements"
"Rate the quality and give feedback"
```

### 7. Song Structure Design
Plan song arrangements:
- Verse/chorus ratio
- Section lengths (bars/measures)
- Intensity curve
- Dynamic changes
- Transition points
- Pacing optimization

**Example:**
```
"Design a song structure for a 4-minute ballad"
"Create arrangement for this melody"
```

### 8. Collaboration & Mashups
Combine musical elements:
- Lyric + melody pairing
- Chord progression optimization for lyrics
- Style blending (fusion)
- Reference track analysis
- Inspiration sourcing
- Trend analysis

**Example:**
```
"Match this melody to these lyrics"
"Blend blues and EDM styles for a fusion track"
```

### 9. Songwriting Tips & Coaching
Get professional songwriting advice:
- Writing techniques
- Common mistakes to avoid
- How to improve flow
- Rhyme density optimization
- Emotional storytelling
- Hook construction

**Example:**
```
"How do I write a better chorus?"
"Tips for improving this bridge"
```

### 10. Music Theory Application
Apply music theory to songwriting:
- Scale selection for mood
- Chord function explanation
- Harmonic analysis
- Tension & resolution
- Modulation suggestions
- Voice leading optimization

**Example:**
```
"What key would work best for this song?"
"Suggest a modulation for the final chorus"
```

## Pro Tips

**Better Lyrics:**
- Use specific imagery
- Tell a story
- Vary line lengths
- Use internal rhymes
- Show emotion, don't tell

**Better Melodies:**
- Singable range
- Memorable hooks
- Avoid awkward jumps
- Repeat with variation
- Clear phrasing

**Better Chords:**
- Fit the mood
- Voice leading smoothly
- Avoid predictability
- Use extensions (jazz)
- Build tension & release
